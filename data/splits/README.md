# 数据划分（尚未执行）

这里保存可复现的划分清单，不存放原始影像副本。

## 划分前必须确认

1. 从 `../metadata/cases.csv` 读取完整记录，不要假设目录名中的数字就是样本数。
2. 核实患者/检查对应关系。当前 `record_id` 只是文件记录 ID，`patient_group_id` 为空。
3. 审计有标签记录的逐帧标注覆盖；无标签影像不能直接作为有监督真值样本。（已完成，见 `../metadata/label_audit.csv`。）
4. 核实跨来源目录、全帧标注版本与其他导出版本是否重叠；不同压缩文件 SHA256 不能证明患者互不重叠。（已完成形状相同视频的逐像素比较：9 对同一录像见 `../metadata/same_video_pairs.csv`，划分时每对必须在同一集合。被剪短或缩放过的同一录像没有查；患者是否重叠见第 2 条，仍未完成。）
5. 先明确实验目标：同分布监督分割、跨站点泛化或半监督学习；不要随手把目录名映射成 train/val/test。

## 后续清单建议

在确认上述信息后，创建例如 `baseline_v1.csv`，包含：

```csv
record_id,patient_group_id,split
```

- `record_id` 必须对应 `../metadata/cases.csv` 中已存在的记录。
- `split` 使用 `train`、`val`、`test`；目前未生成任何实际分配。
- 同一已核实患者/检查/视频及其衍生帧保持在同一集合。
- 记录随机种子、分组依据、筛选条件、数据索引版本/校验值。
- 发布前检查集合不交叉、分组不泄漏、路径存在、标签覆盖满足实验要求。

保留 `raw` 的原始目录不变，通过这些清单决定哪些记录进入哪个集合。
